# 📅 课表 · Operit ToolPkg

一个按「第几周」算的课表。装在 Operit 里，用对话问课，或者点开看整周格子。

**为什么单独做一个**：市面上的通用作息 / 日程表不认教学周——它不知道「这门课只上 4-18 周」「这门只上第 8 周」「这门单周上」。这个插件就是干这个的。

---

## 装完先做三件事

**1. 告诉 AI 你学期第 1 周的周一是哪天**

> 「第 1 周的周一是 2026-09-01」

**2. 把课一节一节报给 AI**

> 「周一第 1、2 节高等数学，A101，王老师，1 到 16 周」
> 「周三第 3、4 节大学英语，B203，李老师，1 到 16 周」

**3. 有假就记上**

> 「10 月 1 号到 7 号放假」
> 「10 月 10 号周六补周三的课」

也可以不进对话，直接编辑数据文件（格式见下）。

## 8 个工具

| 你说 | 工具 | 得到什么 |
|---|---|---|
| 今天上什么课 | today | 今天的课、教室、老师、总时长；放假就说放假中 |
| 这一周的课 | week | 整周排课，晚间第 9–12 节也列 |
| 下一节课 | next | 往后 14 天里最近一节，还有多久、几点、在哪 |
| 课表清单 | courses | 全部课程 |
| 设置 | config | 第 1 周周一、总周数、皮肤、显示项 |
| 放假表 | holiday | 查看 / 添加 / 删除停课假期 |
| 补课日 | makeup | 查看 / 添加 / 删除调休补课日 |
| 自检 | selftest | 验周次解析和过滤，不改数据 |

## 数据文件

`/sdcard/Download/Operit/data/xu_timetable/timetable.json`

第一次打开界面会自动生成，里面自带三门示例课（高等数学、大学英语、体育），删掉换成你自己的就行。

```json
{
  "meta": {
    "week1_monday": "2026-09-01",
    "weeks_total": 18,
    "slots": [ { "n": 1, "start": "08:00", "end": "08:45" } ],
    "holidays": [],
    "makeups": []
  },
  "settings": { "theme": "ink", "show_room": true, "show_teacher": true },
  "courses": [
    { "name": "高等数学（一）", "teacher": "王老师", "room": "A101",
      "day": 1, "slots": [1, 2], "weeks": "1-16", "color": "#E8695C" }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `week1_monday` | 学期第 1 周的周一日期，一切周次从这天推 |
| `weeks_total` | 一学期多少周（1–30） |
| `slots` | 每节课的起止时间，默认 12 节，按你学校改 |
| `day` | 星期几，周一=1 … 周日=7 |
| `slots`（课程内） | 第几节，可多个，`[1,2]` 就是连堂 |
| `weeks` | 见下 |
| `color` | 这门课在界面上的颜色 |
| `holidays` | `[{name, from, to}]`，闭区间，首尾都算 |
| `makeups` | `[{date, as_day, part}]`，`part` 不填=整天，`day`=只补白天，`evening`=只补晚上 |

## 周次怎么写

| 写法 | 意思 |
|---|---|
| `4-18` | 第 4 到 18 周 |
| `8` | 只上第 8 周 |
| `1-16单` | 第 1 到 16 周里的单周 |
| `2-16双` | 第 2 到 16 周里的双周 |
| `4-18,20` | 多个用逗号隔开 |

## 界面

Operit 工具箱里点「📅 课表」。上面一张可折叠月历，有课的日子点小圆点；下面两个页签——**今天**（一节一张卡）和**整周**（第 1–12 节格子）。三种皮肤：`ink` 午夜金 / `strawberry` 草莓牛奶 / `mint` 雾薄荷。

## 隐私

所有数据只写在本机的 `data/xu_timetable/` 下，插件不联网、不上传。

## 卸载

关掉包，然后删掉 `data/xu_timetable/` 目录。
